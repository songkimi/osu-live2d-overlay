# ComboOverlay

给 osu!mania 用的 Live2D 悬浮窗：角色待在游戏画面旁边，随连击和断连击切表情、说语音、对口型。

> 早期开发版本。配置项和界面都还可能变。

## 现在能做什么

- ✅ 透明、置顶、**点击穿透、不抢焦点** —— 硬要求是"绝不干扰打歌"
- ✅ 位置和大小可调，拖动移动、右下角缩放
- ✅ 待机动作循环；跨过设定的连击数时切表情
- ✅ 断连击按"断之前手里有多少连击"分两档反应，**低于门槛完全不反应**
  （玩得菜的时候一直被安慰只会更难受，所以宁可不理）
- ✅ 语音与表情**完全解耦**：同一件事分别决定"演什么"和"说什么"；
  一个情绪里放多个语音会随机挑，且不会连着重复同一句
- ✅ 说话时嘴巴跟着开合，说完自动闭上交还给待机动作
- ✅ 目光跟随鼠标（点击穿透的窗口收不到鼠标事件，所以由程序读光标位置喂给它）
- ✅ 行为**全部由 `config.json` 控制**：换模型、换表情、换语音、改阈值都不用改代码

## 怎么跑起来

需要 Windows + .NET 10 + [tosu](https://github.com/tosuapp/tosu)（读取游戏数据）+ osu!（stable 或 lazer）。

1. 先启动 tosu（默认监听 `127.0.0.1:24050`）
2. 改 `config.json` 里的模型目录、语音目录等路径
3. `dotnet run`
4. **看不到悬浮窗的话**：把游戏的显示模式切换一次（全屏 ↔ 无边框），一次就好

### 需要你自己准备的东西（仓库里不带）

| 东西 | 为什么不在仓库里 | 怎么准备 |
|---|---|---|
| Live2D 模型 | 各人自备（购买或自制），授权不允许分发 | 准备一个 Cubism 3+ 的模型目录，填进 `config.json` 的「模型」 |
| `web/vendor/live2dcubismcore.min.js` | Live2D 官方专有授权，不能随仓库分发 | 从 Live2D 官网的 Cubism SDK for Web 里取；**本地没有时页面会自动从官方 CDN 加载** |
| 语音文件 | 各人自备 | 放一个目录，填进 `config.json` 的「语音」 |

### 热键

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+T` | 进/出调整模式（拖动移动、右下角缩放） |
| `Ctrl+Alt+V` | 试听语音（每按一次换一类情绪） |
| `Ctrl+Alt+1` / `2` / `3` | 模拟连击 / 模拟断连击 / 模拟"门槛以下"（不开游戏也能测） |
| `Ctrl+Alt+R` | 重载页面 |
| `Ctrl+Alt+Q` | 退出 |

## 说明

- 只通过 tosu 的接口**只读**读取游戏数据，不改游戏内存、不模拟输入。
- 与 osu! 官方（ppy）无关，不包含也不分发任何游戏素材。
- 仓库里的模型补丁机制会在运行时把配置好的动作/表情写进一份**临时副本**，
  不会修改你自己的模型文件。
