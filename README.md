# ComboOverlay

给 osu!mania 用的 Live2D 悬浮窗：角色待在游戏画面旁边，随连击和断连击切表情、说语音、对口型。

> 早期开发版本，配置项和界面都还可能变。

---

## 现在能做什么

- ✅ 透明、置顶、**点击穿透、不抢焦点** —— 硬要求是"绝不干扰打歌"
- ✅ 位置和大小可调，拖动移动、右下角缩放
- ✅ 待机动作循环；跨过设定的连击数时切表情
- ✅ 断连击按"断之前手里有多少连击"分两档反应，**低于门槛完全不反应**
  （玩得菜的时候一直被安慰只会更难受，所以宁可不理）
- ✅ 语音与表情**完全解耦**：同一件事分别决定"演什么"和"说什么"；
  一个情绪里放多个语音会随机挑，且不会连着重复同一句
- ✅ 说话时嘴巴跟着开合，说完自动闭上交还给待机动作
- ✅ 目光跟随鼠标
- ✅ 行为**全部由 `config.json` 控制**：换模型、换表情、换语音、改阈值都不用改代码

## 怎么跑起来

需要这几样东西：

| 需要什么 | 必须有吗 | 说明 |
|---|---|---|
| 本程序 | 必须 | 就是本仓库，`dotnet run` 运行 |
| [tosu](https://github.com/tosuapp/tosu) | 必须 | 一个独立小工具，负责读取游戏数据。先启动它（默认监听 `127.0.0.1:24050`） |
| osu!（stable 或 lazer） | 必须 | 玩的那个 |
| 一个 Live2D 模型 | 必须 | Cubism 3 以上的模型（自己买或自己做） |
| 语音文件 | 可选 | 没有也能用，只是角色不说话 |
| `web/vendor/live2dcubismcore.min.js` | 必须 | Live2D 官方核心文件。**本地没有时会自动从官方 CDN 取**，所以通常不用管 |

**Windows + .NET 10** 才能运行。

启动顺序：先开 tosu → 再开 osu! → 最后开本程序。

> **看不到悬浮窗？** 把游戏的显示模式切换一次（全屏 ↔ 无边框），一次就好。
> 这是游戏独占全屏会挡住所有悬浮窗导致的，不是插件的问题。

## 配置说明

配置文件是 `config.json`，就在程序旁边（用 `dotnet run` 时在项目根目录）。
用**记事本**或 VS Code 打开就能改，改完重开程序生效（**不用重新编译**）。

文件里以下划线开头的键（比如 `"_说明"`）都是给人看的注释，不用管。
JSON 的规矩只有三条：**文字要用英文双引号包起来**、**每项之间用逗号**、**最后一项后面不要逗号**。

### 最少要改两个地方

| 要改的 | 改成什么 |
|---|---|
| `模型` → `目录` | 你的模型文件夹完整路径，例如 `D:\\Live2D\\我的角色` |
| `模型` → `入口` | 那个文件夹里的 `.model3.json` 文件名，例如 `我的角色.model3.json` |

> ⚠️ **路径里的反斜杠要写两个**：`D:\Live2D` 要写成 `D:\\Live2D`。
> 这是 JSON 的转义规则，少写一个程序就读不到。

改完这两处，角色就能显示出来了。**其余的都可以先不动。**

### 模型

```json
"模型": {
  "目录": "D:\\Live2D\\我的角色",          ← 模型文件夹
  "入口": "我的角色.model3.json",          ← 文件夹里的入口文件
  "待机动作": "Idle",                      ← 可以留空，见下
  "待机动作文件": "待机.motion3.json",      ← 可以留空，留空就是站着不动
  "表情": [ ... ]                          ← 可以留空，见下
}
```

- **待机动作**：想让它呼吸/摇摆，就填一个 `.motion3.json` 文件名（相对模型目录）。
  留空 = 站着不动，不会报错。
- 模型文件夹里如果找不到 `.model3.json`，说明这个模型不是 Cubism 格式，
  或者你选错了文件夹。

### 表情（可以先留空）

表情是"连击时换成什么脸"。**留空完全没问题**：角色照样显示、语音照样说、嘴照样动，
只是连击时不切表情。

要填的话，格式是一行一个：

```json
"表情": [
  { "名称": "生气",   "文件": "exp/1.exp3.json" },
  { "名称": "害羞",   "文件": "exp/2.exp3.json" }
]
```

- `名称` 随便起，**但下面「连击触发」里要用的就是这个名字**
- `文件` 是模型目录里的相对路径

**怎么知道我的模型有哪些表情？** 模型文件夹里通常有一个 `.cdi3.json` 文件，
用记事本打开搜索 `Expressions` 就能看到列表；或者看有没有 `exp` 之类的文件夹，
里面的 `.exp3.json` 就是表情。

### 语音（没有就关掉）

```json
"语音": {
  "启用": false,              ← 没有语音文件就写 false
  "目录": "D:\\我的语音",      ← 语音文件夹
  "音量": 0.8,
  "最小间隔毫秒": 300,
  "情绪": [
    { "名称": "高兴", "文件": [ "加油.wav", "最喜欢了.wav" ] },
    { "名称": "伤心", "文件": [ "可惜.wav" ] }
  ]
}
```

- 一个情绪里写**多个文件**时，每次会随机挑一个，而且不会连着重复同一句
- **文件多的时候省事写法**：不写 `文件`，直接在你的语音文件夹里建一个叫「高兴」的文件夹，
  把音频都丢进去 —— 程序会自动收下这个文件夹里的全部音频
- 支持 `.wav` `.mp3` `.ogg` `.m4a` `.aac` `.flac` `.opus`

### 位置和大小

调之前先按 `Ctrl+Alt+T` 进调整模式，能拖动窗口、右下角能缩放。
看着合适了，把对应的数字抄进配置：

```json
"视图": {
  "缩放": 1.0,        ← 1.0 是"角色完整装进窗口"，调大就放大
  "上下位置": 0.0,     ← 放大之后用这个把脸移进画面（正数向下）
  "左右位置": 0.0
}
```

### 连击与失误

```json
"连击触发": [
  { "阈值": 50,  "表情": "圈圈眼", "语音情绪": "高兴" },
  { "阈值": 100, "表情": "害羞",   "语音情绪": "高兴" }
],

"失误触发": {
  "小额门槛": 50,      ← 断连击前手里不到 50 连击 → 什么都不做
  "小额表情": "生气",
  "小额语音情绪": "吐槽",
  "大额门槛": 100,     ← 断连击前手里有 100 以上 → 用大额这一档
  "大额表情": "害羞",
  "大额语音情绪": "伤心"
}
```

- **表情**和**语音情绪**是两件独立的事，各填各的。不想让某件事出声就把语音情绪留空 `""`
- 表情名字和模型里的对不上 → 那一项不生效，但**不影响语音**

### 其它

| 配置项 | 说明 |
|---|---|
| `目光跟随鼠标` | `true` = 角色看着你的鼠标。不想用就改 `false` |
| `调试模式` | `true` = 在画面上显示开发信息，并把日志写到 `%TEMP%\ComboOverlay\debug.log`。**给别人用的时候保持 `false`** |

## 热键

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+T` | 进/出调整模式（拖动移动、右下角缩放） |
| `Ctrl+Alt+V` | 试听语音（每按一次换一类情绪） |
| `Ctrl+Alt+1` / `2` / `3` | 模拟连击 / 模拟断连击 / 模拟"门槛以下"（**不开游戏也能测**） |
| `Ctrl+Alt+R` | 重载页面 |
| `Ctrl+Alt+Q` | 退出 |

## 关于这个项目

- **开发方式**：创意、需求、玩法设计、每一项取舍和验收由我（`songkimit`）完成，
  代码在 AI 辅助下编写。这也解释了它为什么还在早期阶段 —— 我会自己先玩过再发出来。
- 只通过 tosu 的接口**只读**读取游戏数据，不改游戏内存、不模拟输入。
- 与 osu! 官方（ppy）无关，不包含也不分发任何游戏素材。
- 运行时会把配置好的动作和表情写进一份**临时副本**来加载，
  不会修改你自己的模型文件。
