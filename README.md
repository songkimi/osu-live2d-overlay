# ComboOverlay

给 osu!mania 用的 Live2D 悬浮窗：角色待在游戏画面旁边，随连击和断连击切表情、说语音、对口型。

> 早期开发版本，配置项和界面都还可能变。
>
> **没接触过编程也没关系** —— 下面的步骤是照着做就能完成的，
> 配置只需要用记事本改两行。遇到问题先看「出问题了？对照这里」。

---

## 现在能做什么

- ✅ 透明、置顶、**点击穿透、不抢焦点** —— 硬要求是"绝不干扰打歌"
- ✅ 位置和大小可调，拖动移动、右下角缩放
- ✅ 待机动作循环；跨过设定的连击数时切表情
- ✅ 断连击按"断之前手里有多少连击"分两档反应，**低于门槛完全不反应**
  （玩得菜的时候一直被安慰只会更难受，所以宁可不理）
- ✅ 语音与表情**完全解耦**：同一件事分别决定"演什么"和"说什么"；
  一个情绪里放多个语音会随机挑，且不会连着重复同一句
- ✅ 说话时嘴巴跟着开合，说完自动闭上交还给待机动作
- ✅ 目光跟随鼠标
- ✅ 行为**全部由 `config.json` 控制**：换模型、换表情、换语音、改阈值都不用改代码

## 怎么跑起来

### 你需要准备什么

| 需要什么 | 必须有吗 | 说明 |
|---|---|---|
| 一台 Windows 电脑 | 必须 | |
| **.NET 10 SDK** | 必须 | 到 [dotnet.microsoft.com/download](https://dotnet.microsoft.com/download) 下载安装，一路下一步就行 |
| **tosu** | 必须 | 到 [tosu 的 Releases 页面](https://github.com/tosuapp/tosu/releases) 下载，解压运行。它负责读取游戏数据，**必须先启动它** |
| **osu!**（stable 或 lazer） | 必须 | 你玩的那个 |
| **一个 Live2D 模型** | 必须 | Cubism 3 以上的模型（自己买或自己做）。见下面「模型」 |
| **语音文件** | 可选 | 没有也能用，只是角色不说话 |
| `live2dcubismcore.min.js` | 必须 | Live2D 的官方核心文件。**程序会自己从官方 CDN 下载**，通常不用管 |

### 四个步骤

**第 1 步：装 .NET 10 SDK**
下载后双击安装，一路"下一步"。装完不用管它。

**第 2 步：启动 tosu**
解压 tosu，双击运行。它会打开一个网页控制台（默认 `127.0.0.1:24050`），说明已经好了。
**之后每次都要先开它。**

**第 3 步：改配置**
打开本项目的 `config.json`，至少要改「模型」里的两项。详细说明见下面的**「配置说明」**。

**第 4 步：运行**

1. 用文件资源管理器打开 `ComboOverlay` 这个文件夹
2. 点一下**最上面的地址栏**（显示路径的那一条），把里面的内容全删掉，输入 `cmd`，按回车
3. 会弹出一个黑色窗口，在里面输入下面这行，按回车：

   ```
   dotnet run
   ```

   第一次运行要联网下载依赖，会慢一两分钟；之后再运行就快了。

关掉它：按 `Ctrl+Alt+Q`，或者关掉那个黑窗口。

### 看不到悬浮窗？

把**游戏的显示模式切换一次**（全屏 → 无边框，再切回来），切一次就好，以后都不会再出现。

原因是游戏用"独占全屏"的时候会盖住所有悬浮窗，这是 Windows 的机制，不是插件的问题。

## 配置说明

配置文件是 **`config.json`**，就在 `ComboOverlay` 文件夹里。
用**记事本**打开就能改（右键 → 打开方式 → 记事本）。

改完**重开程序**生效 —— **不需要重新编译**。

### 先认识这个文件

- 以 `_` 开头的项（比如 `"_从哪开始"`）都是给人看的**注释**，不用动它们
- JSON 的规矩就三条：
  1. 文字要用**英文双引号** `"` 包起来（不能用中文引号）
  2. 每一项之间用**英文逗号** `,` 隔开
  3. **最后一项后面不要加逗号**
- 改错了不要紧，程序读不懂配置时会用默认值继续跑，不会崩

### 最少要改两个地方

| 要改的 | 改成什么 |
|---|---|
| `模型` → `目录` | 你的模型文件夹完整路径，例如 `D:\\Live2D\\我的角色` |
| `模型` → `入口` | 那个文件夹里的 `.model3.json` 文件名，例如 `我的角色.model3.json` |

> ⚠️ **路径里的反斜杠要写两个**：`D:\Live2D` 要写成 `D:\\Live2D`。
> 这是 JSON 的转义规则，少写一个程序就读不到，而且不会报错、只是什么都没发生。

改完这两处，角色就能显示出来了。**其余的都可以先不动。**

### 怎么拿到一个文件夹的完整路径

1. 用文件资源管理器打开那个文件夹
2. 点一下**最上面的地址栏**
3. 路径会变成选中状态，按 `Ctrl+C` 复制

复制出来长这样：`D:\Live2D\我的角色`
填进配置时要写成：`D:\\Live2D\\我的角色`

### 模型

```json
"模型": {
  "目录": "D:\\Live2D\\我的角色",          ← 模型文件夹（必填）
  "入口": "我的角色.model3.json",          ← 文件夹里的入口文件（必填）
  "待机动作": "Idle",                      ← 可以留空
  "待机动作文件": "待机.motion3.json",      ← 可以留空，留空就是站着不动
  "表情": [ ... ]                          ← 可以留空
}
```

**怎么确认我的模型能用？** 打开模型文件夹，看**有没有 `.model3.json` 结尾的文件**：

- 有 → 就是它，把它填到「入口」
- 没有 → 这个模型不是 Cubism 格式（可能是 Live2D 老版本或别的软件做的），本程序用不了

**待机动作**：想让它呼吸、摇摆，就填一个 `.motion3.json` 文件名（相对模型文件夹的路径）。
留空 = 站着不动，**不会报错**。

### 表情（可以先留空）

表情是"连击时换成什么脸"。

**留空完全没问题**：角色照样显示、语音照样说、嘴照样动，只是连击时不切表情。

要填的话，格式是一行一个：

```json
"表情": [
  { "名称": "生气",   "文件": "exp/1.exp3.json" },
  { "名称": "害羞",   "文件": "exp/2.exp3.json" }
]
```

- `名称` 随便起，**但下面「连击触发」里要用的就是这个名字**（两边必须一模一样）
- `文件` 是相对模型文件夹的路径

**怎么知道我的模型有哪些表情？**

1. 模型文件夹里通常有一个 `.cdi3.json` 结尾的文件，用记事本打开，搜索 `Expressions`，里面就是表情名单
2. 或者看有没有 `exp` 之类的文件夹，里面的 `.exp3.json` 就是表情文件
3. 都没有的话，这个模型可能没导出表情 —— 那就留空

### 语音（没有就关掉）

```json
"语音": {
  "启用": false,              ← 没有语音文件就写 false
  "目录": "D:\\我的语音",      ← 语音文件夹
  "音量": 0.8,                 ← 0 到 1 之间
  "最小间隔毫秒": 300,          ← 两句语音之间至少隔多久，防止连发
  "情绪": [
    { "名称": "高兴", "文件": [ "加油.wav", "最喜欢了.wav" ] },
    { "名称": "伤心", "文件": [ "可惜.wav" ] }
  ]
}
```

- 一个情绪里写**多个文件**时，每次会随机挑一个，而且不会连着重复同一句
- **文件多的时候用省事写法**：不写 `文件` 这一项，直接在你的语音文件夹里建一个叫「高兴」的文件夹，
  把音频全丢进去 —— 程序会自动收下这个文件夹里的所有音频
- 支持的格式：`.wav` `.mp3` `.ogg` `.m4a` `.aac` `.flac` `.opus`
- 填完之后按 `Ctrl+Alt+V` 可以试听（每按一次换一类情绪），这样不用开游戏也能确认配好没有

### 位置和大小

1. 启动程序，按 **`Ctrl+Alt+T`** 进入调整模式（会出现黄色虚线框）
2. 拖动窗口移动、拖**右下角**缩放
3. 满意之后，把你调的数字抄进配置：

```json
"视图": {
  "缩放": 1.0,        ← 1.0 是"角色完整装进窗口"，调大就放大
  "上下位置": 0.0,     ← 放大之后用这个把脸移进画面（正数向下）
  "左右位置": 0.0
}
```

> 调整模式里的数值会显示在窗口上，照着抄就行。

### 连击与失误

```json
"连击触发": [
  { "阈值": 50,  "表情": "圈圈眼", "语音情绪": "高兴" },
  { "阈值": 100, "表情": "害羞",   "语音情绪": "高兴" }
],

"失误触发": {
  "小额门槛": 50,      ← 断连击前手里不到 50 连击 → 什么都不做
  "小额表情": "生气",
  "小额语音情绪": "吐槽",
  "大额门槛": 100,     ← 断连击前手里有 100 以上 → 用大额这一档
  "大额表情": "害羞",
  "大额语音情绪": "伤心"
}
```

- **表情**和**语音情绪**是两件独立的事，各填各的
- 不想让某件事出声，就把对应的语音情绪留空：`""`
- 连击阈值想改成 100/200/400/800 这种更稀疏的节奏，改数字就行（一行一个档位）
- 表情名字和模型里的对不上时，**那一项不生效，但不影响语音**

### 其它配置

| 配置项 | 说明 |
|---|---|
| `目光跟随鼠标` | `true` = 角色看着你的鼠标位置。不想用就改 `false` |
| `调试模式` | `true` = 在画面上显示开发信息，并把日志写到 `%TEMP%\ComboOverlay\debug.log`。**给别人用的时候保持 `false`** |

## 装好了吗？对着这个清单验一遍

**不用开游戏**，启动程序后依次按：

| 按什么 | 应该看到 |
|---|---|
| `Ctrl+Alt+1` | 角色换成 50 连击对应的表情 |
| `Ctrl+Alt+3` 连按三次 | 依次是：大额失误表情 → 小额失误表情 → **什么都没发生**（这是对的，门槛以下不反应） |
| `Ctrl+Alt+V` | 有语音出声，同时**嘴巴跟着动** |
| `Ctrl+Alt+T` | 出现黄色虚线框，可以拖动和缩放 |
| `Ctrl+Alt+Q` | 程序退出 |

都正常的话，就可以开游戏试试了。

## 出问题了？对照这里

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| 完全看不到窗口 | 游戏是独占全屏 | 把游戏显示模式切换一次（全屏 ↔ 无边框） |
| 窗口在那儿但是空的 | 模型没加载出来 | 检查 `模型.目录` 和 `模型.入口`；确认那个文件夹里真的有 `.model3.json` |
| 一直白屏或黑屏 | 缺 `live2dcubismcore.min.js` 而且没联网 | 手动下载它，放进 `web\vendor\` 文件夹 |
| 角色出来了但一动不动 | 没配待机动作 | 填 `模型.待机动作文件`；不填也没关系，只是不动 |
| 连击到了也不切表情 | 表情名字和模型对不上 | 检查「连击触发」里的名字，是否和「模型.表情」里的 `名称` 完全一样 |
| 连击完全没反应 | tosu 没连上 | 确认 tosu 已经启动、游戏已经开着；程序状态栏会提示连接情况 |
| 断连击没反应 | 连击没到门槛 | 这是故意的（见上面「连击与失误」）；想改就调低 `小额门槛` |
| 没有声音 | 语音没启用 / 路径不对 / 格式不支持 | 检查 `语音.启用` 是不是 `true`、`语音.目录` 对不对；按 `Ctrl+Alt+V` 试听 |
| 有声音但嘴不动 | 这个模型没有口型参数 | 把 `口型.启用` 改成 `false` 就不折腾了；日志里会说明原因 |
| 窗口挡住了游戏 | 不会的 | 窗口是**点击穿透**的，鼠标会直接穿过它点到游戏上 |
| 想把窗口换位置、改大小 | | 按 `Ctrl+Alt+T` 进调整模式拖动，然后把数值抄进「视图」 |
| 想让程序看着干净点 | 有一堆绿色小框、文字 | 把 `调试模式` 改成 `false`（默认就是 false） |

还搞不定的话：把 `%TEMP%\ComboOverlay\debug.log` 打开看看（需要先把 `调试模式` 设为 `true`
并重启程序），里面会写清楚每一步做到哪、哪一步失败了。

## 关于这个项目

- **开发方式**：创意、需求、玩法设计、每一项取舍和验收由作者完成，
  代码在 AI 辅助下编写。这也是它还在早期阶段的原因 —— 会先自己玩过再发出来。
- 只通过 tosu 的接口**只读**读取游戏数据，不改游戏内存、不模拟输入。
- 与 osu! 官方（ppy）无关，不包含也不分发任何游戏素材。
- 运行时会把配置好的动作和表情写进一份**临时副本**来加载，
  不会修改你自己的模型文件。
